# Fathih Apriandi

Personal portfolio website for Fathih Apriandi, showcasing selected projects, technical experience, certificates, and contact information.

## Live Website

Visit the portfolio at [fathandi.github.io](https://fathandi.github.io).

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- Lucide React

## Development

The source project uses Node.js and npm.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The generated static files are written to `dist/` and can be deployed to any static hosting service.

## Deployment

The `main` branch contains the production build served by GitHub Pages.
